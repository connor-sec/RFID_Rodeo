# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.3 | Yes |
| Older releases | No |

1.3 is the supported release. Reports against older builds will not be addressed unless they also affect 1.3.

## Reporting a vulnerability

Report security issues privately. Do not open a public GitHub issue, discussion, or pull request for a suspected vulnerability.

Use GitHub private vulnerability reporting, which opens a draft security advisory only the maintainers can see:

[Report a vulnerability](https://github.com/connor-sec/RFID_Rodeo/security/advisories/new)

You need a GitHub account. The same form is linked from the repository **Security** tab as **Report a vulnerability**. GitHub's description of the process is [Privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

Include the version you tested, what you observed, and the impact. Please give the maintainer time to respond before any public disclosure.

## Authorized use

RFID Rodeo is an offline reference and calculator for authorized security research and education. Use it only inside an expressly authorized and documented testing scope. It transforms values you enter. It does not read, write, transmit, or clone a physical card by itself. Accessing, duplicating, or using access-control credentials without authorization may violate law, contract, or organizational policy.
